AUM IELTS - STUDENT WEBSITE (version 6)

All files are in ONE folder. Every page contains its own design.

FILES
  index.html          Home page (also contains the list of sessions)
  session-01.html     Session 1: Mock test (reading, writing, homework, links)
  session-02.html     Session 2: Writing Task 1, step by step
  session-03.html     Session 3: Reading skills (five parts)
  notes.html          Writing notes (Task 1)
  reading-notes.html  Reading notes
  passages.js         The reading passages for Session 3
  template.html       Copy this to make a new session

UPDATE GITHUB
  1. Unzip this file.
  2. In your repository, delete the old session-04.html to session-07.html
     if you uploaded them.
  3. Add file > Upload files: drag in all the files. Commit changes.
  4. Wait 1-2 minutes, then open the site in an Incognito window.

ADD THE SESSION 3 READING PASSAGES (once)
  1. On GitHub, open passages.js and click the pencil icon.
  2. In your Google Doc ("session 3" tab), copy Reading Passage 1
     (Eiffel Tower) and paste it where it says PASTE THE PASSAGE HERE.
     Keep one empty line between paragraphs.
  3. Do the same for Reading Passage 2 (Olympics) and 3 (hibernation).
  4. Commit changes.

ADD A NEW SESSION
  1. Copy template.html and rename it, for example session-04.html.
  2. Edit the text (on GitHub: open the file, click the pencil icon).
  3. In index.html, find "TO ADD A SESSION" and edit the line for
     session 4: change the title and description, and set ready: true.
  4. Commit. The site updates in 1-2 minutes.

The site is public: do not put student names or scores on it.
