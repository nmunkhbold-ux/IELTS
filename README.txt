AUM IELTS WRITING - STUDENT WEBSITE (version 2)

All files are in ONE folder. There are no sub-folders, and the design is
inside every page, so each page always looks right.

FILES
  index.html        Home page (also contains the list of sessions)
  notes.html        Task 1 notes
  session-01.html   Session 1
  session-02.html   Session 2
  template.html     Copy this to make a new session

UPLOAD TO GITHUB
  1. Unzip this file on your computer first.
  2. In your repository, delete any old files and folders
     (old index.html, notes.html, the "assets" and "sessions" folders,
     and any .zip file).
  3. Add file > Upload files. Select ALL the files from the unzipped
     folder and drag them in together. Commit changes.
  4. Settings > Pages: Deploy from a branch, main, / (root).
  5. Wait 1-2 minutes, then open https://YOUR-USERNAME.github.io/REPO-NAME/
     and press Ctrl+Shift+R to refresh.

ADD A NEW SESSION
  1. Copy template.html and rename it, for example session-03.html.
  2. Edit the text (on GitHub: open the file, click the pencil icon).
  3. Open index.html, find "TO ADD A SESSION" near the bottom, and add or
     edit one line, for example:
     { n: 3, title: "Task 1: line graphs", about: "Describing trends", file: "session-03.html", ready: true, tags: ["Line graph"] },
  4. Commit. The site updates in 1-2 minutes.

The site is public: anyone with the link can open it. Do not put student
names or scores on it.
